How does padding differ with margin?

Based on my observation, padding shrinks the area that contents occupied inside the wrapper like div, while margin adds space between wrappers like div outside.

What does box-sizing: border-box do?

This box sizing border box tells the browser to include the padding and border inside the elements width and height to avoid having 1 element bigger than the other element with the same height and width but one with padding or border.

How can excessive margin affect the layout?

For me, having an excessive margin will affect the alignment of the wrappers like div cards causing overflows and some text outside will be out of place.
